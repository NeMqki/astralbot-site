読み上げbot

チャンネルの発言を、Discord の VC で読み上げる BOT です。声は VOICEROID2・A.I.VOICE・VOICEVOX・CeVIO から、一人ずつ選べます。

はじめ方 声を変える 読み方 辞書 コマンド一覧 困ったとき お問い合わせ

自分のサーバーに導入したいときは、一度 Discord（@NeMqki）か info@nemqki.moe までご相談ください。自分で動かすこともできます。

はじめ方

  1. VC に入る先に自分が読み上げてほしい VC に入ります。
  2. 読み上げたいチャンネルで /joinコマンドを打ったチャンネルの発言を読み上げます。
  3. 発言する同じ VC にいる人の発言を、順番に読み上げます。
  4. 終わったら /leaveVC から人がいなくなったときは、自動で抜けます。

声を変える

最初に発言すると声が自動で決まり、そのあとは同じ声で読みます。好きな声にしたいときは、次のコマンドを使います。設定は一人ずつ保存されます。

/voices
使える声の一覧を見ます。エンジンで絞り込めます。
/voice ずんだ
声を変えます。名前の一部を入力すると候補が出ます。何も入れないと、今の設定を表示します。
/tune speed:1.2 pitch:0.9
速さと高さを変えます。どちらも 0.5〜2.0 で、1.0 が標準です。
/test
今の声で試しに読み上げます。先に /join が必要です。

読み方

発言は、次のように整えてから読み上げます。

発言の内容読み方
; ； // / で始まる発言読みません
URL「ユーアールエル」
コードブロック「コード省略」
スポイラー（|| で囲んだ文字）「ネタバレ」
メンション相手の名前、ロール名、チャンネル名
絵文字・スタンプ読みません
添付ファイルだけの発言「添付ファイル」
同じ文字の連続（wwwwwww など）3文字に短くします
300文字を超える発言300文字まで読んで「以下略」

読み上げ前に発言を消すと、その発言は読みません。読んでいる途中なら止まります。

辞書

読み間違える言葉は、辞書に登録すると直せます。辞書はサーバーで共通で、誰でも編集できます。

/dict_add word:VC reading:ブイシー
言葉と読みを登録します。
/dict_remove word:VC
登録を消します。
/dict_list
登録されている言葉を見ます。
  • 登録できるのは 500 件までです。言葉は 30 文字まで、読みは 60 文字までです。
  • ひらがな・カタカナ1文字と、記号だけの言葉は登録できません。
  • 英数字の言葉は、英単語の途中には当たりません。AI を登録しても MAIN の読みは変わりません。

コマンド一覧

読み上げ

/join
VC に接続して、このチャンネルの読み上げを始めます。
/leave
VC から切断します。
/skip
今の読み上げをスキップします。
/clear
読み上げ待ちを全部消します。

確認

/status
エンジンの状態と、接続中のサーバー数を見ます。
/help_read
コマンドの一覧を Discord 上で見ます。
/credit
音声エンジンの規約についての案内を見ます。

サーバーの設定 サーバー管理権限

/volume percent:100
読み上げの音量を 10〜200% で変えます。100 が標準です。
/readname on:True
発言者の名前も読みます。初期設定はオフです。同じ人が続けて発言したときは、60秒間は名前を省きます。
/announce on:True
VC の入退室を読み上げます。初期設定はオフです。

困ったとき

発言を読んでくれない

次の3つを確認してください。

  • BOT と同じ VC に自分がいる
  • /join を打ったチャンネルで発言している
  • 発言が ; や / で始まっていない

別のチャンネルを読ませたいときは、同じ VC にいる状態で、そのチャンネルでもう一度 /join を打ってください。

「別のVCで使用中です」と出る

BOT は1つのサーバーで同時に1つの VC にしか入れません。今の VC で /leave するか、同じ VC に移動してください。

読み上げが飛ばされた

読み上げ待ちは 20 件までで、超えた分は読みません。読み飛ばしたときは、チャンネルに件数を知らせます。

声が出ない、エラーが出る

/status でエンジンの状態を確認してください。「未接続」や「不調」と出ている間は、そのエンジンの声で読めないことがあります。/voice で別のエンジンの声に変えると読める場合があります。

BOT が VC から抜けた

VC に人がいなくなると自動で抜けます。通信の不具合で切れたときは、自動で入り直してチャンネルに知らせます。戻らないときは /join を打ってください。

クレジットについて

音声エンジンとキャラクターには、それぞれ利用規約があります。VOICEVOX の音声を公開・配信するときは、「VOICEVOX:キャラクター名」のクレジット表記が必要です。公開サーバーで使うときは、各エンジンの規約を確認してください。
