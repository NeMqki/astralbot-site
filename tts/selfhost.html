自分で動かす

読み上げbotのプログラムは GitHub で公開しています。自分の BOT として動かせば、自分のサーバーで使えます。動かしている PC の電源が入っている間だけ動きます。

必要なもの

  • Windows の PC：VOICEVOX 以外のエンジンは Windows で動かします。
  • Python 3.10 以上：python.org から入れます。
  • FFmpeg：ffmpeg.org から入れて、PATH を通します。コマンドプロンプトで ffmpeg -version と打って確認できます。
  • 音声エンジンを1つ以上：VOICEROID2、A.I.VOICE、VOICEVOX、CeVIO のどれかです。無料で試すなら VOICEVOX が手軽です。エンジンと音声ライブラリは各自で用意してください。

インストール

  1. プログラムをダウンロードするZIP をダウンロードして、好きな場所に展開します。
  2. 展開したフォルダでコマンドプロンプトを開くフォルダのアドレスバーに cmd と入力すると開けます。
  3. 必要なものを入れるpip install -r requirements.txt
  4. VOICEROID2 を使うときだけ、追加で入れるpyvcroid2 は別に入れます。
    pip install https://github.com/Nkyoku/pyvcroid2/archive/refs/heads/master.zip

Discord で BOT を作る

  1. アプリを作るDeveloper Portal で「New Application」を押します。
  2. Message Content Intent をオンにする「Bot」のページにあります。オフのままだと発言を読めません。
  3. トークンをコピーする同じページの「Reset Token」で表示されます。あとで使います。
  4. サーバーに招待する「OAuth2」のページで、スコープの bot と applications.commands を選びます。権限は「チャンネルを見る」「メッセージを送信」「接続」「発言」を選びます。できた URL を開いて招待します。

自分のサーバーだけで使うなら、「Bot」のページの「Public Bot」をオフにすると、ほかの人が招待できなくなります。

設定する

  1. token.txt を作るプログラムと同じフォルダに作り、トークンを1行だけ書きます。
  2. config.txt を作るconfig.example.txt をコピーして名前を変えます。
  3. config.txt を編集する最初は次の2つを設定します。ほかの項目は、ファイルの中の説明を見て必要なら変えてください。
owner_ids
自分の Discord ユーザーID を書きます。ここに書いた人だけが /restart と /presence を使えます。
engines
使うエンジンだけを残します。VOICEVOX だけなら engines = voicevox です。[voice] の random_engines も同じエンジンに変えてください。

起動する

  1. 音声エンジンを起動するVOICEVOX はアプリを起動しておきます。
  2. Start.bat をダブルクリックするBOT が終了しても自動で起動し直します。止めるときはウィンドウを閉じます。
  3. Discord で /join を打つVC に入ってから打ちます。あとの使い方は使い方のページを見てください。

便利な設定

どれも config.txt に書きます。変更したら BOT を起動し直してください。

allowed_guilds
入っていてよいサーバーの ID を書きます。それ以外のサーバーからは自動で抜けます。
auto_resume / auto_rejoin
再起動のあとや、通信が切れたあとに、VC へ自動で戻ります。初期設定はオンです。
log_reads / log_read_text
読み上げの記録をログに残すかを決めます。文章そのものを残す log_read_text は、初期設定ではオフです。
max_queue / max_text_len
読み上げ待ちの上限と、1つの発言で読む最大文字数です。

BOT を2つ動かす

同じ VC 以外でも同時に読み上げたいときは、BOT を2つ作ります。プログラムを別のフォルダにコピーするか、python MultiTTSBOT.py config_bot2.txt のように設定ファイルを分けます。

  • token_file と data_dir は BOT ごとに分けてください。
  • 声の設定と辞書を共有するなら、両方の shared_dir に同じフォルダを指定します。
  • CeVIO は同時に1つのアプリしか接続できないので、片方の BOT だけで使ってください。

困ったとき

「トークンがありません」と出る

token.txt がプログラムと同じフォルダにあるか確認してください。メモ帳の設定によって token.txt.txt になっていることがあります。

コマンドが Discord に出てこない

招待するときに applications.commands を選んだか確認してください。起動したあと、反映まで少し時間がかかることがあります。Discord を再読み込み（Ctrl + R）すると出ることもあります。

VC に入るのに、声が出ない

FFmpeg の PATH が通っているか、エンジンが起動しているかを確認してください。エンジンの状態は /status で見られます。

発言を読まない

Developer Portal で Message Content Intent がオンになっているか確認してください。発言する人が BOT と同じ VC にいることも必要です。

原因がわからない

BOT の画面と、logs フォルダの bot.log にエラーが残ります。お問い合わせするときは、トークンや名前が写っていないことを確認してから送ってください。

新しい版に更新する

BOT を止めて、新しい MultiTTSBOT.py で置き換えます。config.txt や user_settings.json はそのまま残してください。変更点はパッチノートにあります。

注意

  • トークンは絶対に人に見せないでください。知られると BOT を乗っ取られます。漏れたときは、すぐに「Reset Token」で作り直してください。
  • user_settings.json、dictionary.json、logs フォルダには、ユーザーID や名前が入ります。公開しないでください。
  • 発言の読み上げのために、メッセージの本文を BOT が受け取ります。ほかの人のサーバーで動かすときは、そのことを伝えてください。
  • 音声エンジンとキャラクターの利用規約とクレジット表記は、動かす人の責任で守ってください。VOICEVOX は「VOICEVOX:キャラクター名」の表記が必要です。
