Astralbot

アストラルパーティーのキャラ・マップのランダム抽選と、メンバー募集ができる Discord BOT です。
A Discord bot for random character/map draws and player recruitment in Astral Party.

使い方自分で動かす

コマンド / Commands

  • /キャラ (/character) — キャラをランダムに抽選 / Draw random characters
  • /マップ (/map) — マップをランダムに抽選 / Draw a random map
  • /セット (/set) — マップとキャラをまとめて抽選 / Draw a map and characters together
  • /リスト (/list) — 登録されているキャラとマップ / Registered characters and maps
  • /持ってないキャラ (/unowned) — 持っていないキャラの設定 / Set characters you don't own
  • /募集 (/recruit) — メンバー募集 / Recruit players
  • /募集設定 (/recruit-settings) — 募集でメンションするロール（管理者用） / Roles to mention (admins)
